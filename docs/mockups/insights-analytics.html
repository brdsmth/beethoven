Insights, expanded

OpenInspect (ColeMurray/background-agents) ships an Analytics page with five tabs: Overview, Usage, Cost, Pull requests and People. Each tab has KPI tiles, daily trends, ranked lists and sortable tables. Our Insights page is one long scroll and already covers things OpenInspect doesn't, such as first-try rate, cycles and failure reasons. These mockups bring in OpenInspect's metrics, add a few of our own, and keep everything on one page.

Static mockups using the app's own design tokens. Names and numbers are made up. Hover any chart mark for its tooltip. Badges: OpenInspect means OpenInspect has it; new means neither product has it today.

  • One sidebar link, the same as today. The filters (range, team, scope, repository) sit above the tabs and apply to every tab.
  • Overview keeps today's quality story: first-try rate, cycles and outcomes. The other tabs are where you go to dig in.
  • Tab and filters go in the URL (#/insights/cost?days=30&team=payments), so a link opens the exact view.

Alternative: a separate Analytics page

Insights would stay about quality, and a new Analytics page would cover usage, cost and people.

  • Two pages with the same filters, and the same numbers (sessions, spend, PRs) shown in both
  • People have to guess which page has the number they want

Alternative: one longer page

Keep scrolling and add more cards.

  • Already about 6 screens tall, and this would double it
  • No way to link to "the cost view"
  • Every query runs on every visit

A possible order

  • 1. Tabs and filters. Split today's page into Overview, Usage, Pull requests and Reliability. Add scope, a repository filter, the comparison with the previous period, and URL state. Only data we already have.
  • 2. Cost and People. Model and team tables, expensive runs, the leaderboard, the person sheet and getting started.
  • 3. Events. An index or rollup for events, then sandbox start time and tool errors.
  • 4. Tokens. Save token usage per prompt and session, then the token and cache cards.

"About this data" popover

  • Counts sessions created in the window, in your timezone.
  • Quality only counts sessions that have settled (nothing queued or running).
  • You only see sessions you can read; private sessions are left out for everyone else.
  • Spend is what the agent reported; runs billed to a subscription may show $0.
  • PR states refresh from GitHub every 10 minutes.

OpenInspect features left out

  • Breakdowns by provider and harness: we run one harness (Claude Code), so they would always show one row.
  • 30-second auto-refresh: refreshing when you return to the tab is enough for daily numbers.
